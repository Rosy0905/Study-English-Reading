# 英语一真题阅读资料库 · 使用指南

2010–2026 年考研英语一真题阅读，每篇含做题模式、复盘模式、手写笔记。
全部功能本地运行，笔迹存在你自己的浏览器里。

> 想知道每个文件是干嘛的，看 [architecture.md](architecture.md)。
> 想看改了什么，看 [log.md](log.md)。

---

## 一、怎么用起来

三种打开方式，效果完全一样：

| 方式 | 怎么做 | 适合谁 |
| --- | --- | --- |
| **本地文件夹** | 下载整个仓库，双击 `index.html` | 只想自己用，不想传到网上 |
| **GitHub Pages** | 仓库设置里开启 Pages，得到一个网址 | 想在手机 / 平板上用 |
| **本地服务器** | 在项目目录跑 `python -m http.server`，访问 `localhost:8000` | 调试用 |

**建议用 GitHub Pages。** 因为浏览器对 `file://` 有限制，本地双击打开虽然能正常书写和导出，
但某些浏览器的表现不如正常网址稳定；而且换设备时只要开网址就能接着用。

## 二、四种页面

| 页面 | 入口 | 能做什么 |
| --- | --- | --- |
| **主页** | `index.html` | 浏览全部篇目、搜索、收藏、标记学完、看最近学习、管理备份 |
| **做题模式** | 卡片上的「做题模式」 | 逐句拆解阅读，左栏原文图右栏讲解，可批注 |
| **复盘模式** | 卡片上的「复盘模式」 | 方法论精讲，按步骤展开，可批注 |
| **手写笔记** | 卡片上的 ✍️ | 自由手写，垫着真题底稿写 |

**三个子页之间顶栏可以互跳**，做题页能跳复盘和笔记页，复盘页能跳做题和笔记页，
笔记页能跳做题和复盘页。互相跳转时会自动记住你在那一页的进度。

## 三、主页

### 3.1 卡片

每年 4 张卡（Text 1–4），卡上有三个入口和两个标记。
卡片从上到下的顺序是：**紫点 → 篇名 → 学完 → ★ → 三个入口按钮**。

| 看到的东西 | 意思 |
| --- | --- |
| 紫色小点 | 这篇已收录（有内容可做） |
| 「学完」 | 点一下标记做完，再点取消 |
| ★ | 点一下收藏，再点取消 |
| 三个按钮 | 做题模式 / 复盘模式 / ✍️ 手写笔记 |

**有些篇目只有笔记没有做题复盘。** 卡片上会显示「暂未更新」的占位。
目前 68 篇里做题 38 个、复盘 35 个，**2022、2023、2026 这三年整年只有笔记**。
作者一直在更新，数字会变。

### 3.2 搜索

顶部搜索框输入年份或篇目关键词，比如 `2014`、`text2`、`Text 2`，卡片实时筛选。
搜不到时页面中间会提示换个词。

搜索状态下不会恢复滚动位置 —— 搜索结果的布局和全量列表不同，位置没意义。

### 3.3 最近学习

主页顶部有一排最近点过的篇目卡片，最多 8 个，从左到右由新到旧。

**两种情况返回主页表现不一样，这是故意的：**

| 你怎么进去的 | 点「主页」回来 |
| --- | --- |
| 从顶部「最近学习」点进去的 | **回到页面顶部** |
| 从下面某年的篇目卡片点进去的 | **停在原来那个位置** |

为什么这样设计：从最近学习进去的，你可能已经翻了很久才找到这一篇，
回主页理应从头看；而从年份卡片跳过去的，你本来就是停在某个年份上，回原地才不丢上下文。

### 3.4 位置记忆

主页、做题页、复盘页都会记住你上次停在哪。

- **刷新一下** → 回到原位置
- **关掉标签页** → 位置记录清空（有意设计，避免第二天回来还停在上周的地方）

### 3.5 导入 / 导出 / 清空

三个按钮都在主页顶部右侧。详见第六节。

## 四、三个子页怎么用

### 4.1 手写笔记页

点卡片上的 ✍️ 进来。**所有篇目共用这一个页面**，靠地址栏里的 `id` 区分是哪篇。

顶栏四个按钮：

| 按钮 | 作用 |
| --- | --- |
| **主页** | 回主页 |
| **底稿** | 显示 / 隐藏底下那张真题图。挡住视野时关掉它 |
| **导出** | 把笔迹导出成图片或 PDF |

底稿默认是**显示**的，写笔记时就着原文写。嫌它挡视野就点「底稿」关掉。

**68 篇的底稿图全齐**，包括只有笔记的那几年 —— 所以不管哪一篇，✍️ 点进去都有原文垫着。

### 4.2 做题模式

顶栏：显示全部 / 上一步 / 下一步 / 重置 / 章节跳转 / 进度。

**复盘页支持键盘**：→ 下一步、← 上一步、空格 下一步。批注状态下按 `Esc` 切阅读模式。

**默认就是批注模式，打开就能直接写。**

| 操作 | 怎么做 |
| --- | --- |
| 看全文 | 「显示全部」切成通读模式，再点一次回来 |
| 逐步精读 | 用「上一步 / 下一步」按钮 |
| 跳到某段 | 用右上角的章节下拉框 |
| 看某句在原文哪里 | 讲到某句时左栏原文图会同步高亮 |

**批注写在左栏原文图上**，笔迹钉在图上，滚动和缩放都跟着内容走。

**分栏可以拖**：中间那条竖线拖动调左右比例，比例会记住。
窗口宽度小于 1100px 时自动切成上下单栏。

### 4.3 复盘模式

顶栏和做题页类似，但内容是方法论精讲。

**这一页有两处可以批注：**

| 位置 | 批注跟着什么走 |
| --- | --- |
| **左栏真题图** | 跟着内容走，并按素材分层：真题词汇标注是一层笔迹、真题试卷页是另一层，从词汇标注切到真题页时前者的笔记不再串上来，切回去还在 |
| **右侧解析** | 跟着步骤走。翻到下一步就是另一份笔迹 |

**左栏可能不出现。** 有些步骤是纯文字讲解，没有配图，这时左边就收起来了，全屏显示文字。

## 五、手写工具（三处共用一套）

笔记页、做题页、复盘页用的都是同一套工具，手感完全一样。

### 5.1 工具栏

| 按钮 | 作用 |
| --- | --- |
| 🖊 | 钢笔，画实线 |
| 🖍 | 荧光笔，涂半透明、**方头** |
| ◻ | 橡皮 |
| ● | 调颜色（点开调色盘，可存自定义色） |
| ─ | 调粗细（钢笔、荧光笔、橡皮各记各的） |
| ↶ | 撤销 |
| ↷ | 重做 |
| 🗑 | 清空当前这张纸（会弹确认） |
| ☝ | 手指写字开关 |
| 👀 | 临时隐藏 / 显示所有笔迹 |

**工具栏可以拖着走**，拖到屏幕边缘会吸附，竖着放会变成窄条。

### 5.2 隐藏工具栏

**做题页和复盘页**不想被工具栏挡住（比如平板上写字），点顶栏「阅读模式」把工具栏藏起来。
**笔迹仍然显示、仍然可以看**，只是不能写。做完再点一下切回批注模式。
按 `Esc` 也能快速切换。

> 手写笔记页没有这个切换，工具栏一直都在。

### 5.3 三个隐藏技巧

| 想要的效果 | 怎么做 |
| --- | --- |
| 长按自动变橡皮 | 按住不动 0.4 秒 |
| 画直线 | 画完停住不动 0.5 秒，自动拉直 |
| 隐藏笔迹专心看原文 | 点 👀 或切「阅读模式」 |

### 5.4 手势

| 手势 | 作用 |
| --- | --- |
| 触控笔写字 | 直接写，不怕手掌误触（写的时候手掌蹭屏页面不会乱滚） |
| 单指滑动 | 滚动页面 |
| 双指捏合 | 做题页整页、复盘页**左栏底图**可缩放（比例记住）；复盘页右侧解析不缩放，改用手动拖分隔条调宽窄，避免文字回流让笔迹跑位 |
| 手指写字 | 需要先开 ☝ 开关，默认关着是为了防止误触 |

**多指同时写字也可以了**，两根手指各写各的，不会互相顶掉。

### 5.5 撤销的边界

**刷新页面后撤销栈会清空** —— 这是有意接受的取舍，
刷新之后没法继续撤销上一步，但已经写好的笔迹不会丢（那部分自动保存）。

## 六、数据备份与恢复

> 这节的信息量最大，建议看完。**导入是覆盖不是合并**，搞清楚了再动手。

所有笔迹存在浏览器本地数据库（IndexedDB），**每次写完自动保存**，不用手动点保存。

笔迹除了进 IndexedDB，**每写完一笔还会同步写一份到 localStorage 作即时备份**，专门防平板刚写完就秒关页面、最后几笔没提交的情况。这份备份用「最近 3 篇」策略（LRU）：只留你正在写的几篇，老篇备份自动清，所以占的 localStorage 很小（通常几百 KB ~ 1MB 内），不会挤到同域名下其他 Pages 项目（如经济学项目）的存储额度。

### 6.1 笔迹分三类

三个地方都能写批注，备份时**分开打包、分开统计**：

| 类别 | 在哪写 | 弹窗里叫什么 |
| --- | --- | --- |
| 做题页批注 | 做题页的原文图和题目图 | 做题页批注 |
| 复盘页批注 | 复盘页的左栏真题图和右侧解析 | 复盘页批注 |
| 真题页批注 | 手写笔记页 | 真题页批注 |

### 6.2 导出

点主页顶部「导出」，弹窗里会先让你选导出范围，然后有三件事：

**上面是两个下拉框**：年份（默认「全部年份」）和篇目（选了具体年份才能选篇目），
它们只影响「导出 PDF」，不影响「备份 JSON」——JSON 永远是全量的。

| 选项 | 做什么 |
| --- | --- |
| **备份 JSON** | 全部笔迹 + 收藏 / 学完 / 最近学习，打包成一个文件下载 |
| **导出 PDF** | 按上面选的范围导出做题页的文章页 + 题目页，带批注 |
| **清空所有数据** | 见 6.5 |

弹窗里会列清楚每一类各有几篇、总共多大，数字是实时读出来的。

> **为什么不显示笔数？** 因为这个数字总被误解。橡皮擦本身也算一条记录、
> 撤销会减掉一条，算出来总不像「我写了多少字」。所以干脆不给，看篇数就够。

### 6.3 导入：先看清楚再确认

点「导入」选文件后，**不会立刻写入**。会先弹一个「这份备份里有这些内容」，
列清楚这份文件里有什么、会覆盖本机什么、总共多大。**点「确认导入」才真的写，点取消什么都不动。**

蓝色弹窗是导入，红色弹窗是清空，不会搞混。

### 6.4 覆盖规则（重要）

这是最容易踩坑的地方：

| 数据 | 导入时怎么处理 | 举个例子 |
| --- | --- | --- |
| 三类批注 | **按篇覆盖**，同一篇的整条替换 | 本机某篇写了 20 笔，备份里同一篇只有 5 笔 → 导完变成 5 笔，**不是合并** |
| 备份里有、本机没有的 | **新增** | 备份里有 2025 年那篇 → 直接写进来 |
| 收藏 / 学完 / 最近学习 | **整段替换** | 本机 9 条收藏 + 5 条学完，备份里只有 3 条收藏、0 条学完 → 导完只剩 3 条收藏，学完被清空 |
| 备份里标记为空时 | **不写**，本机保持原样 | 文件里三项都是空的 → 当作「那台机器本来没用过这些标记」，不会把你本机的清掉 |

一句话记法：**批注按篇覆盖，主页标记整段替换，空标记不动。**

所以导入前一定看一眼弹窗里的「会覆盖本机」那一行。
如果本机有 9 条收藏而备份只有 3 条，导完那 6 条就没了 —— 这不是 bug，
是备份文件本身就只记了 3 条。想保住就先导一份本机备份，导完再补回去。

**旧备份也能导。** v1 格式的老文件里没有主页标记，导入时那三项显示「无」，
你本机的收藏 / 学完 / 最近学习保持原样。

### 6.5 清空所有数据

点下去会再弹一层红色确认，把要删的东西逐项列清楚并给出总大小。

确认后清四层：

| 清什么 | 具体内容 |
| --- | --- |
| 笔迹 | 全部笔记（做题页、复盘页、真题页批注） |
| 主页标记 | 收藏、学完、最近学习 |
| 本地设置 | 工具偏好、颜色、粗细、缩放、分栏比例、位置记忆 |
| 浏览器缓存 | 页面缓存 |

**没法撤销。** 清之前先导一份 JSON。

**清空前请把本站的其它标签页全部关掉。** 这一步很关键：

- 只关掉一个标签页时，数据库删不掉，会提示「笔记没删干净：ekz-notes-v2 被占用，
  关掉本站其他标签页再试」。这时候别硬重试，先去把别的标签页关干净。
- 更隐蔽的一种：**清空完了统计却还是「3 篇做题页有数据」**。
  原因是还开着的做题页标签页内存里抱着清空前的笔迹，它一切走或一关闭
  又把旧笔迹写回去了（2026-10-04 已修，但老页面缓存里没有这个修复）。

**养成习惯：清空 → 关掉所有本站标签页 → 重新打开主页看统计。**
统计确实变成 0 才算真清干净了。

### 6.6 关于安全

导出的 JSON 是**纯文本**，里面只有笔迹坐标，**没有任何可执行代码**。
所以转发给别人、放在微信里，都不会出问题 —— 对方只是能看见你写了什么内容。

反过来也成立：导入一个别人发来的 JSON 也是安全的，站点会把它当纯数据读。

### 6.7 建议

定期导一份备份到网盘。换设备或换浏览器时：**旧环境导出 → 新环境导入**，无缝衔接。

**注意**：清浏览器数据（不只是清缓存）会把笔迹一起清掉。重要笔记别只存在浏览器里。

## 七、常见问题

**Q：笔迹会丢吗？**
正常使用不会，每次写完自动保存。但清理浏览器数据会连数据库一起清掉，
所以重要笔记一定要导出备份。刷新页面不会丢，只是撤销栈清空。

**Q：为什么刷新后回到顶点了 / 位置不对？**
多半是浏览器缓存住了旧脚本，按 `Ctrl + F5` 强制刷新。
但也有一种情况是正常的：从「最近学习」进子页再回主页，本来就会强制回顶部。

**Q：为什么关掉标签页再回来，位置就不记了？**
有意设计的。位置记忆只活在当前标签页里，关掉就清空，
避免第二天回来还停在上周的老地方。笔迹和设置是长期的，不受影响。

**Q：复盘模式打开有点慢？**
首次加载要等几秒（解析内容多、图片大）。打开过一次之后浏览器有缓存，第二次快很多。

**Q：复盘页左边是空的？**
左栏是真题图，只有需要对照原文的步骤才有。纯文字讲解的步骤左栏会自动收起，
这是正常的，不是加载失败。

**Q：有些卡片显示「暂未更新」？**
作者还没更新那篇，或者只做了一边。哪边做了就显示哪边的入口。

**Q：手机上能用吗？**
可以。用 GitHub Pages 拿到网址，手机浏览器打开就能用。
单指滑动滚页面，双指捏合缩放，触控笔写字不怕手掌误触。
但手机没有鼠标右键，长按变橡皮需要按住不动。

**Q：平板上手掌会不会误触？**
不会。写的时候手掌蹭到屏幕页面不会乱滚。
如果你的设备容易误触，可以在工具栏打开「手指写字」主动控制。

**Q：顶栏按钮挤在一起或错位？**
`Ctrl + F5` 强制刷新。样式跟着脚本一起更新，缓存旧版就会错位。

**Q：互跳按钮点了说「未找到文件」？**
旧版本有这个问题（路径算错），现已修正。若仍遇到，同样 `Ctrl + F5`。

**Q：能同时在两个标签页打开吗？**
可以，但**清空所有数据时不行** —— 数据库删不掉，会提示你关掉其他标签页。
这是浏览器的限制，不是故障。

**Q：放大后发现有些浅色的斜杠，100% 看不出来？**
那不是残留，是真的画在数据里的笔迹。
2026-10-04 查过一次（2017t3 题目页那批淡粉色），结论是：
橡皮当时屏上擦干净了，但**擦除动作没存进数据**——橡皮本身工作正常，
实测能擦掉 95.8% 的荧光笔像素。所以不会再出现「擦了却还在」的新情况，
但历史留下的旧数据要清掉才行。
这类残留的判别方法：100% 缩放看不见、放大才看见，颜色是极浅的半透明色带。
处理办法是从主页导入一份清理过的备份（导入是整段覆盖，会把旧笔迹顶掉）。

**Q：数据会被别的标签页弄乱吗？**
正常书写不会（每个标签页各写各的槽位，保存时互不覆盖）。
但**清空所有数据**和**导入**是全局操作，另一个标签页开着就可能冲突，
所以这两件事之前先把本站其它标签页关掉。

**Q：笔记页怎么是白纸，没垫底稿？**
68 篇的底稿图都是齐的，正常不会出现这种情况。
如果真遇到了，多半是图片没加载完 —— 刷新一下，或者点「底稿」关掉再打开试试。

## 八、一句话总结

十七年真题，四种页面，一套工具。
笔迹自动保存但只在这台设备上，**记得导出**。
导入是覆盖不是合并，**看清再确认**。
