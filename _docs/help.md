# 考研英语一真题阅读资料库 · 使用说明与功能指南

本资料库是一个面向考研英语（一）真题阅读复习的本地化学习系统，纯静态网页，双击 `index.html` 打开即用，无需安装任何东西。
覆盖 2010–2026 年阅读真题（更新中），每篇均为做题、复盘、手写笔记三模式，笔记底稿为无水印真题页。
所有学习数据默认只保存在当前浏览器本地，不会自动上传云端。建议定期使用"备份"导出 JSON 文件，防止换设备、换浏览器或清理缓存导致数据丢失。

---

## 一、总览

本资料库把历年阅读真题按年份分组陈列，每篇提供三个入口：做题模式、复盘模式、手写笔记页。三处手写全部共用同一套粉色工具栏与手写引擎，笔迹钉在真题图上，滚动、缩放都跟内容走。

主页还配有搜索、收藏、学完标记、最近学习、备考攻略与数据备份等功能。没上架的篇目显示虚线"暂未更新"占位；只有单边的篇目缺的一侧同样显示占位，手写笔记按钮缺失时显示虚线小笔图标。

学习数据保存在当前浏览器本地。换设备、换浏览器、清理浏览器数据、使用无痕模式，都可能导致数据丢失，因此建议定期导出备份。

---

## 二、快速开始

第一次使用，双击打开 `index.html`，就是资料库主页。主页按年份分组展示所有篇目卡片，顶部搜索框支持搜年份或篇目（比如输入 2014、text2）。

每张卡片右上角有两个小按钮：**学完 / ✓ 学完**用于标记这篇做完了（再点一次取消）；**★** 用于收藏，收藏的卡片会排到前面。卡片下方三个入口：**做题模式**在真题页上乱涂乱画；**复盘模式**真题加解析对照批注；**✍️ 手写笔记**进入单张笔记纸。主页顶部"📖 攻略"是备考方法总结，"备份"是数据导入导出。

主页还有"最近学习"区，显示最近打开过的篇目，接着学不用翻找。直接双击进入任意一篇做题，写画的内容会自动保存，回到主页"最近学习"里就能接着来。

---

## 三、做题模式

打开默认就是批注模式，直接在真题页上写画：

- 笔迹钉在图上，滚动、缩放都跟内容走，不会飘
- 右下角按钮可切换**阅读模式**（隐藏工具条，笔迹仍显示），再点切回批注模式
- 左右分栏的分隔条可以拖动调整比例，比例会记住，下次打开保持
- 右下工具有**导出**按钮，点开弹窗两个选项：**导出为图片**（PNG，文章页和题目页各一张）、**导出为 PDF**（两页批注合成一个 PDF 文件），批注都包含在内

---

## 四、复盘模式

左栏真题图、右栏解析，两栏都能直接批注。同一张图的笔迹跟着步骤走，换新图会自动开新笔记。左右分栏同样可拖、比例记忆。只有复盘没有做题的篇目打开后为单页居中显示。复盘页没有导出按钮（导出只在做题页和笔记页有）。

---

## 五、手写笔记页

从卡片 ✍️ 进入，是一张自动适配大小的笔记纸，底下垫着这篇文章页和题目页（可一键显隐）。

- 笔记自动保存，写多少都不怕丢
- 顶栏"导出"点开弹窗两个选项：**导出为图片**（PNG，单张笔记图）、**导出为 PDF**（单页 PDF 文件），都垫着底稿一起导出
- 直接双击 index.html 用浏览器打开（不经过任何服务器）也能正常导出，底稿图内置了数据包，画布不会被污染

三个模式的对比：

| 模式 | 页面构成 | 用途 | 笔迹存储 |
|---|---|---|---|
| 做题模式 | 单页真题图 | 第一遍做题，划生词、标线索 | 钉在真题图上，按图分篇 |
| 复盘模式 | 真题图 + 解析双栏 | 对答案、学思路、二次批注 | 跟随步骤走，换图开新笔记 |
| 手写笔记 | 单张笔记纸 + 底稿 | 自由整理：错因、同义替换、长难句 | 按篇目独立保存 |

## 六、手写工具栏（三处共用）

做题、复盘、笔记三个页面用的是完全同一套粉色工具栏，从左到右每个键都是：

**书写工具（三选一，选中的会高亮）**

- **钢笔**：自由书写，笔迹实色不透明，适合写字、划线
- **荧光笔**：半透明粗笔，适合大面积划重点，透过它还能看清底下的字
- **橡皮**：擦除笔迹，只会擦到笔迹，不会碰到真题图

**颜色与粗细**

- **颜色球**：显示当前工具正在用的颜色。点开调色盘，里面有预设色块和自定义色块；在自定义区挑好颜色点"保存"就能存成常用色；自定义色块**长按可删除**；点 **⇅** 进入排序模式，拖动色块调整顺序，再点一下保存
- **粗细滑块**：拖动调整笔的粗细，旁边的数字实时显示；钢笔和荧光笔的粗细分开记忆，互不影响

**操作**

- **↶ 撤销 / ↷ 重做**：一步一步回退或恢复最近的笔迹操作
- **🗑️ 清空**：把当前页面（或当前图）上的笔迹全部清掉，会先弹窗确认，不怕手滑
- **☝️ 手指写字**：平板上切换"手指当笔写"模式；打开后手指直接在纸上写字，手掌搭在屏幕上也不误触
- **✍️ 触控笔（手写笔）**：笔只负责写字，写的时候手掌蹭到屏幕页面也绝不会乱动（笔优先防误触）
- **👆 手指移动界面**：不开"手指写字"时，单指滑动＝滚动页面，**双指捏合＝自由放大缩小**（做题、复盘、笔记三个页面都支持，缩放比例会记住）
- **👀 显示 / 隐藏笔迹**：暂时藏起所有笔迹看干净的原图，再点一下恢复，笔迹不会丢

**通用习惯**

- 工具条可以**拖动贴边**（上下左右吸附），挡住内容时拖走就好
- 三页偏好互通：在任何一页改颜色、粗细、排序，全站生效并记住

## 七、数据备份与恢复

所有笔迹与偏好存在浏览器本地数据库（IndexedDB），自动保存。主页"备份"按钮：

- **导出**：把全部笔记数据打包成一个 JSON 文件保存到本地
- **导入**：选择 JSON 文件恢复，同名笔记会被覆盖

建议定期导出一份备份到网盘或电脑，双保险。换电脑或换浏览器时，先在旧环境导出，再在新环境导入即可无缝衔接。

## 八、常见问题

- **笔迹会丢吗？** 正常使用不会，自动保存；但清理浏览器数据会连数据库一起清掉，先导出备份。
- **直接双击打开 index.html（不开服务器）导出会失败吗？** 不会，底稿图内置了数据包，导出图片 / PDF 都能用。
- **手机 / 平板怎么用？** 直接浏览器打开网站即可；单指滑动滚页面，双指捏合缩放，触控笔写字不怕手掌误触。本地文件夹方式也支持。
- **复盘模式打开有点慢？** 复盘页解析内容多、内嵌图大（单页 4-6MB），首次加载需要等几秒到几十秒（看网速），打开过一次浏览器就有缓存，第二次会快很多。
- **有些卡片显示"暂未更新"？** 作者还没更新那篇（或缺其中一边），上架后占位会自动变成入口。
- **2026 年的怎么没有？** 作者页面还没出 2026 的篇目，等更新了就上架；2026 年无水印底稿页码已提前摸好，随时能提。
- **笔记页底稿可以隐藏吗？** 可以，顶栏"底稿"按钮一键显隐，适合只想看自己笔记的时候。

## 九、目录结构

```
index.html          主页（年份分组 / 搜索 / 收藏 / 学完 / 最近学习 / 备份）
manifest.js         篇目清单 ← 新增篇目只改这个文件
guide.html          备考攻略
notes.html          手写笔记页
assets/ink-paper.js    手写纸张引擎（全站共用）
assets/ink-toolbar.js  手写工具栏（全站共用，粉色）
assets/mark-engine.js  批注适配层
assets/note-fab.js     真题页批注按钮（脚本自动注入）
assets/ekz-db.js       笔记数据库统一入口（ekz-notes-v2）
assets/pdfimg/         导出专用底稿数据包（保证双击直开也能导出）
library/            各年份文件（做题 / 复盘 html + 笔记底稿图）
scripts/            上架与维护脚本
_docs/              本指南与工作日志
```

## 十、更新与维护（新增一篇）

作者更新新篇目时，一键上架：

```bash
python scripts/add-paper.py --year 2015 --text 2 \
  --do "作者包/做题.html" --review "作者包/复盘.html"
```

脚本自动完成：复制改名入库、提取底稿图、更新 manifest.js、注入批注按钮（幂等，重复跑无副作用）。

笔记底稿统一用无水印 PDF 版（`scripts/extract-pdf-underlay.py`），页码定位规律：Text 1–4 从全年真题 PDF 的 p4 起，每篇两页（文章 p4/6/8/10，题目紧随其后 +1）。改完跑 `python scripts/make-imgdata.py` 重打包，`node scripts/smoke.js` 冒烟验收。
