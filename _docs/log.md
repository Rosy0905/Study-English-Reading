# 工作日志 · 网页版修复记录

> 26/10/02 建立第一代版本

---

## 一、说明

本文件记录资料库网页的搭建与修复过程，按日期编号，只记最终结果。方便日后不小心破坏格式或清除数据时对照补回。

## 二、版本与存储策略

目前本地版本为唯一主版本，GitHub 仓库（Study-English-Reading）为同步备份。本地更新后随时推送同步。学习数据（笔迹）不在仓库里，只存浏览器本地，务必定期在主页"备份"处导出 JSON。

## 三、已修复问题与已完成功能

### 26/10/02

（1）上午建立第一代版本：主页（年份分组 / 搜索 / 收藏 / 学完 / 最近学习 / 备份）与做题、复盘、手写笔记三模式。

（2）三页共用同一套手写引擎与工具栏（ink-paper + ink-toolbar），粉色系；批注笔迹钉在真题图上，滚动缩放跟内容走。

（3）复盘模式左真题右解析双栏批注，分栏可拖、比例记忆；同一图笔迹跟步骤走，换图自动开新笔记。

（4）工具栏完整功能：调色盘排序与自定义色、粗细分工具记忆、撤销重做、☝️ 手指写字切换、拖动贴边；三页偏好互通。

（5）修复四类深层问题：撤销重做失效（栈未压初笔）、IndexedDB 坏库静默失败（升级 v2 自愈重建）、笔记页底稿加载前黑线闪现、复盘单页居中闪跳。

（6）新增笔记导出为图片 / PDF（含底稿）；file:// 直开画布防污染，底稿图压成数据包按篇懒加载。

（7）下午批量上架 25 篇（作者更新包 42 文件盘点，26 成对 + 4 仅做题 + 6 仅复盘），manifest 达 26 篇；21 篇复盘页打单页居中补丁；冒烟测试 40/40 通过。

（8）制作粉色花朵图标六件套（仿经济学项目花款），全站接入 favicon。

（9）git 建仓（main 分支）并完成首次提交。

（10）单边篇目笔记页底稿缺失：改用无水印真题 PDF 提取，缩略图网格人工定位页码，全量 26 篇统一替换为无水印版；页码规律固化进提取脚本，顶部广告自动裁除。

（11）主页占位完善：整套缺失显示双格"暂未更新"（四字等宽）；笔记按钮缺失时显示同款虚线框白描笔图标。

（12）README 改为极简入口，新增 _docs/help.md 使用指南与 _docs/log.md 工作日志。

（13）晚上推送到 GitHub：Study-English-Reading 仓库。期间排查出本机 curl 直连 GitHub SSL 失败、git 需 schannel 后端、令牌需勾选 Contents/Administration 写权限三个问题，逐个解决后推送成功。
