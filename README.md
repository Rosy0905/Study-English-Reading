# 英语一真题阅读资料库（2010–2025 · 更新中）

纯静态网页，无需安装任何东西，双击 `index.html` 就能用，也可以直接托管到 GitHub Pages。
全部 26 篇均为做题 + 复盘 + 手写笔记三模式，笔记底稿为无水印真题页。

---

## 使用指南

### 1. 打开主页

双击 `index.html`，就是资料库主页。顶部搜索框支持搜年份或篇目（比如输入 2014、text2）。
每张卡片有三个入口：

- **做题模式**：在真题页上乱涂乱画
- **复盘模式**：真题 + 解析对照批注
- **✍️ 手写笔记**：单张笔记纸，左边文章页、右边题目页垫在底下

右上角还有 📖 攻略，是备考方法总结。没上架的篇目显示虚线"暂未更新"占位。

### 2. 标记学习进度

每张卡片右上角有两个小按钮：

- **学完 / ✓ 学完**：标记这篇做完了，再点一次取消
- **★**：收藏，收藏的卡片会排到前面

主页还有"最近学习"区，显示你最近打开的篇目，接着学不用翻。

### 3. 做题模式

打开默认就是批注模式，直接在真题页上写画：

- 笔迹钉在图上，滚动、缩放都跟内容走，不会飘
- 右下角按钮可切换**阅读模式**（隐藏工具条，笔迹仍显示）
- 左右分栏的分隔条可以拖动调整比例，比例会记住

### 4. 复盘模式

左栏真题图、右栏解析，两栏都能直接批注。同一张图的笔迹跟着步骤走，
换新图会自动开新笔记。分栏同样可拖、比例记忆。

### 5. 手写笔记页

从卡片 ✍️ 进入，是一张自动适配大小的笔记纸，底下垫着这篇文章页和题目页（可一键显隐）。
笔记自动保存，写多少都不怕丢。顶栏"导出"可把当前笔记导出为图片 / PDF（含底稿）。

### 6. 手写工具栏（三个页面同一套）

- **钢笔 / 荧光笔 / 橡皮**：调色盘含预设色和自定义色，颜色、粗细分工具记忆
- **撤销 / 重做**
- **☝️ 手指写字**：平板上手掌搭在屏幕上也不误触（手指滚动 ↔ 手指写字切换）
- 工具条可以**拖动贴边**（上下左右吸附）
- 做题、复盘、笔记三页的偏好互通，改一处全站生效

### 7. 数据备份与迁移

所有笔迹存在浏览器本地数据库（IndexedDB），自动保存。主页"备份"按钮可以：

- **导出**：把全部笔记打包成 JSON 文件
- **导入**：换电脑 / 换浏览器时恢复（同名笔记会被覆盖）

建议定期导出一份备份，双保险。

### 8. 常见问题

- **笔迹会丢吗？** 正常使用不会，自动保存；但清理浏览器数据会连数据库一起清掉，记得先导出备份。
- **直接双击打开（file://）导出失败吗？** 不会，底稿图内置了数据包，导出图片 / PDF 都能用。
- **手机 / 平板怎么用？** 整个文件夹拷过去，用支持本地文件的浏览器打开 index.html 即可；手写推荐配合 ☝️ 手指模式。

## 目录结构

```
index.html          主页（年份分组 / 搜索 / 收藏 / 学完 / 最近学习 / 备份）
manifest.js         篇目清单 ← 新增篇目只改这个文件
guide.html          备考攻略
notes.html          手写笔记页
assets/ink-paper.js    手写纸张引擎（全站共用）
assets/ink-toolbar.js  手写工具栏（全站共用，粉色）
assets/mark-engine.js  批注适配层
assets/note-fab.js     真题页批注按钮（脚本自动注入）
assets/ekz-db.js       笔记数据库统一入口（ekz-notes-v2）
assets/pdfimg/         导出专用底稿数据包（file:// 防 canvas 污染）
library/            各年份文件（做题 / 复盘 html + 笔记底稿图）
scripts/            上架与维护脚本
```

## 维护备忘（新增一篇）

```bash
python scripts/add-paper.py --year 2015 --text 2 \
  --do "作者包/做题.html" --review "作者包/复盘.html"
```

脚本自动完成：复制改名入库、提取底稿图、更新 manifest.js、注入批注按钮（幂等）。

笔记底稿统一用无水印 PDF 版（`scripts/extract-pdf-underlay.py`），
页码定位规律：Text 1–4 从全年真题 PDF 的 p4 起，每篇两页（文章 p4/6/8/10，题目紧随其后 +1）。
改完跑 `python scripts/make-imgdata.py` 重打包，`node scripts/smoke.js` 冒烟验收。
