# 英语一真题阅读资料库（2010–2026 · 更新中）

纯静态网页，无需安装任何东西，双击 `index.html` 就能用，也可以直接传 GitHub。

## 结构

```
index.html          主页（年份分组 / 搜索 / 收藏 / 最近学习 / 备份）
manifest.js         篇目清单 ← 新增篇目只改这个文件
guide.html          备考攻略（主页「📖 攻略」点开查看）
notes.html          手写笔记页（单张纸 / 自动保存 / 导出PNG）
assets/note-fab.js  真题页批注按钮（由脚本自动注入）
assets/ink-toolbar.js  手写工具栏（demo 同款，粉色，全站共用）
assets/ink-paper.js    手写纸张引擎（全站共用，笔迹跟内容走）
assets/mark-engine.js  批注适配层（做题/复盘的批注挂载与存取）
assets/ekz-db.js    笔记数据库统一入口（ekz-notes-v2）
scripts/inject-fab.py  给真题 HTML 注入/补回批注按钮
scripts/add-paper.py   一键上架新篇目
library/            各年份的阅读文件（做题模式 + 复盘模式 + 笔记底稿图）
```

## 新增一篇阅读的步骤

通常直接委托小兮处理即可（一条命令搞定）：

```
python scripts/add-paper.py --year 2015 --text 2 --do "作者包/做题.html" --review "作者包/复盘.html"
```

脚本自动完成：复制改名入库、提取文章页/题目页底稿图、更新 manifest.js、
给两个 html 注入批注按钮（幂等，重复跑无副作用）。

## 说明

- 设计原则：打开页面默认就是批注模式；右下角按钮切换「阅读模式」（隐藏工具条，笔迹仍显示）。
  不加栏、不加页、不弹窗。
- 做题模式：真题页上乱涂乱画，笔迹钉在图上，滚动/缩放都跟内容走；左右分栏可拖（比例记忆）。
- 复盘模式：左栏真题图和右栏解析都能直接批注；同一张图的笔迹跟着步骤走，换新图自动开新笔记；左右分栏可拖。
- 工具条与笔记页完全同一套（粉色）：可拖动贴边、调色盘含自定义色、粗细分工具记忆、
  撤销重做、☝️ 手指写字切换（平板用）；「导出为图片」在工具条末尾。偏好两边互通。
- 手写笔记页：单张纸 + 左文右题真题底稿（「底稿」按钮一键显隐）；「导出为图片」在顶栏。
- 备份：主页「导出笔记」一键下载 JSON（含批注），「导入笔记」选文件恢复，无弹窗。
- 数据库：浏览器本地 IndexedDB（ekz-notes-v2），首次自动迁移旧库数据。
- 主页默认全部展开：有内容的年份显示卡片（固定两篇一行），还没收录的年份显示一行占位。
